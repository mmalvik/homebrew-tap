# mmalvik/tap

Homebrew tap for [Tannlaus](https://github.com/mmalvik/tannlaus), a macOS menu bar app that turns Bluetooth off while your Mac sleeps.

```
brew install --cask mmalvik/tap/tannlaus
```

The full name taps this repository and marks the cask as trusted, which Homebrew requires for casks outside its official taps.

The cask is updated automatically by the Tannlaus release workflow. Don't edit `version` or `sha256` by hand.
